# MomAI WhatsApp

Conecte o WhatsApp ao MomAI para acompanhar conversas e responder sem pegar o celular. A extensão lê apenas as conversas dos contatos e grupos que você escolher.

## O que você pode fazer

- Escolher contatos e grupos prioritários para receber avisos.
- Enviar mensagens e respostas por voz ou texto.
- Mandar fotos e prints que estão no computador. Na primeira vez em cada pasta, a MomAI pede sua confirmação.
- Dar apelidos aos contatos, como Mãe, Amor ou Chefe.
- Pedir um resumo de áudios e textos longos.
- Conectar pelo QR code no painel ou no chat.

## Exemplos

- "Mande um WhatsApp para a Mãe dizendo que já terminei o trabalho."
- "Tem mensagem nova no WhatsApp?"
- "Responda que confirmo o almoço."
- "Mande a foto que indiquei para o João."
- "Adicione o João aos contatos prioritários."

## Como conectar

1. Abra o MomAI e clique no ícone do WhatsApp.
2. No celular, abra o WhatsApp e entre em Aparelhos conectados > Conectar um aparelho.
3. Aponte a câmera para o QR code na tela do computador.
4. Escolha os contatos e grupos que quer acompanhar.

## Privacidade

A conexão vai do seu computador direto para o WhatsApp, sem servidor intermediário. As conversas e a lista de contatos ficam no seu computador. A MomAI só lê mensagens dos contatos que você autorizou.

## Permissões

- **Rede:** para conectar ao WhatsApp.
- **Arquivos (leitura):** para enviar imagens e prints que você indicar.
