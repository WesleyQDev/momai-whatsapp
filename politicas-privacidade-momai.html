  • Tratamento: toda operação realizada com dados pessoais, como coleta, produção, recepção, classificação, utilização, acesso, reprodução, transmissão, distribuição, processamento, arquivamento, armazenamento, eliminação, avaliação ou controle da informação, modificação, comunicação, transferência, difusão ou extração;

Dados Coletados e Finalidade do Tratamento

Dados processados localmente

A Aplicação processa e armazena exclusivamente no seu computador:

  • Conversas e comandos enviados à assistente;
  • Notas, lembretes e anotações criados por você;
  • Configurações e preferências da Aplicação;
  • Registros de áudio para processamento de voz (armazenados localmente).

Base legal: Legítimo interesse (Art. 7º, IX, LGPD). Você escolhe livremente utilizar a Aplicação e fornecer as informações necessárias ao seu funcionamento.

Finalidade: Permitir o funcionamento da assistente, execução de comandos, reconhecimento de voz e personalização da experiência.

Conexões externas necessárias

A Aplicação realiza conexões com serviços de terceiros exclusivamente para as seguintes finalidades:

  • GitHub (api.github.com, github.com): verificação de atualizações da Aplicação e download de novas versões. Nenhum dado pessoal é enviado;
  • Repositórios Python (pypi.org): instalação de dependências como Faster Whisper para reconhecimento de voz local;
  • Microsoft Edge TTS (speech.microsoft.com): síntese de voz, habilitada opcionalmente pelo usuário. O texto da resposta é enviado para conversão em áudio;
  • DuckDuckGo (duckduckgo.com): pesquisa na web quando solicitado pelo usuário. Regido pela política de privacidade do DuckDuckGo;
  • GitHub (download de extensões): download de extensões da loja quando solicitado pelo usuário.

Base legal: Legítimo interesse (Art. 7º, IX, LGPD) e execução do serviço solicitado pelo usuário.

Compartilhamento com Terceiros

A Controladora não compartilha seus dados pessoais com terceiros para fins de marketing, propaganda ou qualquer outra finalidade comercial. As conexões com terceiros descritas acima ocorrem exclusivamente para viabilizar o funcionamento da Aplicação conforme solicitado por você.

Direitos do Titular (Art. 18, LGPD)

Você, como titular de dados pessoais, tem os seguintes direitos:

  • Confirmação e acesso: saber se tratamos seus dados e acessar os dados processados;
  • Correção: solicitar a correção de dados incompletos, inexatos ou desatualizados;
  • Anonimização, bloqueio ou eliminação: solicitar a anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desconformidade com a LGPD;
  • Portabilidade: solicitar a portabilidade dos dados a outro fornecedor de serviço;
  • Eliminação: solicitar a eliminação dos dados tratados com base no seu consentimento;
  • Informação: ser informado sobre as entidades públicas e privadas com as quais a Controladora compartilhou seus dados;
  • Revisão: revisar decisões automatizadas.

Para exercer seus direitos, entre em contato pelo e-mail: wesleyqueirozdeveloper@gmail.com.

Você também pode a qualquer momento excluir todos os seus dados localmente desinstalando a Aplicação ou apagando manualmente a pasta de dados da MomAI em seu computador.

Retenção de Dados

Seus dados permanecem armazenados localmente no seu computador pelo tempo que você desejar utilizar a Aplicação. Você pode removê-los a qualquer momento:

  • Excluindo conversas, notas e lembretes individualmente pela interface da Aplicação;
  • Desinstalando a Aplicação (os dados podem ser preservados ou removidos conforme sua escolha);
  • Apagando manualmente a pasta de dados da MomAI.

Medidas de Segurança

A Controladora adota as seguintes medidas para proteger seus dados:

  • Todo processamento de IA (LLM, reconhecimento de voz, síntese de voz local) ocorre inteiramente no seu computador;
  • Não existe servidor remoto da MomAI para coleta ou armazenamento de dados;
  • Não são utilizados cookies, rastreadores ou identificadores únicos para monitoramento;
  • Não é necessário criar conta ou fornecer dados pessoais para utilizar a Aplicação.

Transferência Internacional de Dados

As conexões externas realizadas pela Aplicação (GitHub, PyPI, Microsoft, DuckDuckGo) podem envolver a transferência de dados para servidores localizados fora do Brasil. Ao utilizar a Aplicação, você consente com estas transferências para as finalidades descritas nesta Política. Cada serviço de terceiros possui sua própria política de privacidade que rege o tratamento dos dados.
