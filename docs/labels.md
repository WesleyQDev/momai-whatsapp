# Labels do Projeto

Convenções de labels usadas no repositório MomAI.

| Label | Descrição | Cor |
|-------|-----------|-----|
| `bug` | Comportamento inesperado ou incorreto | `#d73a4a` |
| `documentation` | Melhorias ou acréscimos em documentação | `#0075ca` |
| `enhancement` | Novas funcionalidades ou pedidos de melhoria | `#a2eeef` |
| `governance` | Processos, políticas, templates e regras do projeto | `#7057ff` |
| `help wanted` | Aberto para contribuição externa | `#008672` |
| `question` | Dúvidas que precisam de esclarecimento | `#d876e3` |
| `security` | Vulnerabilidades e reports de segurança | `#000000` |
| `wontfix` | Decisão de não implementar | `#ffffff` |

## Uso Recomendado

- **Issues:** use a label que melhor descreve o tipo de issue.
- **Pull Requests:** use a label correspondente ao tipo de mudança.
- Issues de segurança devem usar `security` e **nunca** conter detalhes da vulnerabilidade no corpo — siga o processo em [SECURITY.md](../SECURITY.md).
