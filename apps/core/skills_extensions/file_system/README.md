# File System Extension

Esta extensão permite que a MomAI interaja com arquivos locais de forma segura.

## Funcionalidades
- Listagem de diretórios
- Leitura e escrita de arquivos
- Movimentação, cópia e exclusão
- Busca de arquivos

## Segurança
As operações são restritas ao diretório `apps/core/data/storage` por padrão para evitar acesso não autorizado a arquivos do sistema.
