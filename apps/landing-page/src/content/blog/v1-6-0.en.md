Between version 1.2 (April) and 1.6.0 (July), MomAI went through 17 releases. What started as a local AI chat that answered questions and managed reminders turned into a platform with extensions, WhatsApp integration, a note editor, voice commands, and a more robust security system.

This post is a rundown of what changed, area by area — no hype, just the facts.

---

## Extensions: from internal tools to an ecosystem

In version 1.2, MomAI's extensions were limited to internal tools: web search, weather forecasts, reminders. The AI called these functions when needed, but the model was rigid — each extension was basically a function the agent could invoke.

Starting from version 1.4, the extension platform was rewritten to support **persistent workers** — background processes that keep connections open. The first major application was **WhatsApp**. The extension maintains a continuous connection through the Baileys protocol, enabling real-time notifications, message sending, group and contact access. Voice commands like "responda" activate the extension directly from the chat.

In version 1.5, extensions gained **their own visual interfaces**. Each extension can declare full screens or side panels that appear inside the app. The architecture is self-contained: the extension is a ZIP file with everything it needs — routes, events, voice commands, and UI. The app loads it dynamically without needing to know what each extension does internally.

The **Extension Store** was redesigned in 1.6 with visual cards, tags, and separate tabs (Store and Installed). It's a straightforward navigation improvement.

A unified **Notification Center** was also added, where all active extensions can display alerts in one place.

The **context prioritization** system was introduced in 1.5: the AI automatically adjusts which tools take precedence depending on the conversation topic. In practice, if you're asking about weather, the weather extension gets priority — no manual configuration needed.

Much of the security and isolation infrastructure was implemented by **Anderson Tavares** ([@AndersonTavares0](https://github.com/AndersonTavares0)): SVG icon sanitization, IPC channel validation, session token protection, and installation integrity verification.

## Note Editor and Memory

The note editor isn't new — it existed in previous versions with basic markdown functionality. What changed in 1.6 was a **complete redesign in Obsidian style**:

- Real-time markdown preview
- Wiki-style links between notes (`[[link to another note]]`)
- Interactive graph showing note connections
- Folder structure in the sidebar
- Auto-save

The most relevant addition is **expandable memory via .md files** (also introduced in 1.6): MomAI now reads Markdown files from the `momai/` folder and uses that content as context for responses. If you keep personal documentation, notes, or custom prompts, the assistant automatically considers that material. You're no longer limited to what the AI learned from previous conversations.

The editor is more solid than before, but still has rough edges — title search works, but there's no full-text search yet.

## Voice: more options, more stability

Version 1.4 introduced the **TTS engine selector**:

- **Edge TTS** (cloud) — more natural voices, requires internet
- **Kokoro** (local) — runs entirely on your machine, CUDA acceleration on NVIDIA GPUs

Both work, and the choice depends on your preference for voice quality versus privacy.

**Call Mode** was rewritten in 1.6 to better synchronize the thread_id between the interface and the Python server. The practical result is fewer mid-call disconnections — a common issue in previous versions.

**Voice commands per extension** also matured. Each extension can register shortcuts: "responda" activates WhatsApp, "pesquise" activates search. The AI learns to recognize these commands in context.

## Interface: incremental changes that add up

No single version brought a visual revolution, but the accumulated changes between 1.2 and 1.6 are noticeable:

- **Drag-and-drop sidebar** (1.6): reorder conversation icons
- **Auto-removal of empty sessions** (1.6): conversations with no messages disappear from the list
- **System tray with live status** (1.6): shows whether the model is loaded, processing, or paused
- **Local settings cache** (1.5.4): Settings opens without loading screen
- **Resilient boot**: panels wait for the server in the background instead of showing errors
- **Progressive loading** (1.6): extensions load in stages, reducing startup time
- **Dev panel** (1.6): better organized logs and diagnostic folder buttons

None of these are revolutionary on their own, but the overall experience is smoother.

## AI Engine

**llama.cpp** was updated from b9165 (present since 1.4) to b10094 in 1.6 — incremental performance and memory improvements.

The biggest change is on the **Ultra tier**: the model was replaced with **Qwen3.5-4B-MTP**, a version with MTP (Multi-Token Prediction) support. Instead of predicting one token at a time, the model predicts multiple tokens per step, then validates the best candidates in one pass. This speeds up inference considerably — especially on hardware with more memory.

The **embedding model** (used for semantic search and memory) also changed: from **Qwen3-Embedding-0.6B** to **LFM2.5-Embedding-350M**. The numbers speak for themselves: 52% lower latency, 41% smaller model size, 5x more consistent performance. For the user, this means faster context searches and more stable memory retrieval.

**Inference parameters** (temperature, top-p) were recalibrated per tier. **System prompts** were rewritten for each tier, reducing inconsistent responses on lower tiers. **Streaming** was rewritten in 1.6 — responses start appearing faster with a smoother flow.

## Security

Between 1.2 and 1.6, security received the most attention — and for good reason: the more integrations a local assistant has, the larger the attack surface.

Key measures implemented by **Anderson Tavares** ([@AndersonTavares0](https://github.com/AndersonTavares0)):

- **SVG sanitization**: extension icons are checked before rendering, preventing XSS
- **IPC validation**: internal communication channels have an allowlist
- **Error sanitization**: error messages don't leak file paths or system details
- **Session token via environment**: no longer appears in process listings
- **Uninstall validation**: extension ID is verified before removing files
- **Integrity verification**: downloaded extensions are validated against the official catalog
- **Malicious redirect blocking**: the app blocks redirects to untrusted sites

Additionally, the **Privacy Panel** (1.5) lets you view and export data stored by each extension. Since 1.5, extension data is auto-saved when closing the app.

## Economy Mode

Introduced in 1.4, Economy Mode automatically detects when you launch a game (Steam, Epic, standalone titles) and pauses the AI to free up resources. The overlay shows how much RAM and VRAM was reclaimed. When you close the game, the AI resumes.

Useful for anyone who games on the same machine and doesn't want to close MomAI. The catalog includes Steam and Epic integrations, detecting popular titles like Cyberpunk 2077, Elden Ring, and Baldur's Gate 3.

---

## The bottom line

From 1.2 to 1.6, MomAI evolved from a chat with internal tools to a platform with third-party extensions, WhatsApp integration, a note editor, and a more mature security posture. The AI engine was updated, voice became more stable, and the interface gained refinements that improve day-to-day use.

There are still rough edges — the note editor is new, the extension ecosystem depends on developer adoption, and some features (like full-text search in the editor) are still pending. But the direction is clear: a local assistant that doesn't depend on the cloud, requires no subscription, and keeps your data on your machine.
