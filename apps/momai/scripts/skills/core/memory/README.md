# Memory Skill (Memória de Longo Prazo)

A Memory Skill permite que a MomAI aprenda e recorde fatos sobre você e seus projetos. Ao contrário da memória de curto prazo (o chat atual), as informações salvas aqui persistem entre diferentes conversas e reinicializações.

### O que ela pode fazer?

- **Anotações Persistentes**: Salve detalhes técnicos, preferências pessoais ou informações de projetos.
- **Busca Semântica**: Recupere informações mesmo que você não lembre as palavras exatas usadas na anotação.
- **Contexto Ampliado**: Permite que a MomAI tenha um "histórico de vida" do que você já discutiu ou planejou.

---

## Exemplos de uso

- "Anote que eu prefiro usar o padrão de cores Zinc neste projeto"
- "Lembre que meu servidor de homologação está no IP 192.168.1.50"
- "O que nós decidimos sobre a arquitetura do banco de dados ontem?"
- "Guarde o link desta documentação: https://..."

## Privacidade

Todas as suas notas são armazenadas localmente em seu computador. A MomAI não compartilha essas informações com servidores externos, garantindo total privacidade sobre seu conhecimento pessoal.
