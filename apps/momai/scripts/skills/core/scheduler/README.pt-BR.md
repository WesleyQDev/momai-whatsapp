# Agendador e Lembretes (Componente de Sistema)

Este componente permite que a MomAI gerencie seus compromissos e lembretes. Ele garante que você nunca perca uma tarefa importante ou um compromisso agendado.

### O que faz por você:
*   **Criação de Lembretes**: Define alertas para horários específicos (ex: "Me lembre de beber água a cada 2 horas").
*   **Gestão de Tarefas**: Organiza sua lista de afazeres com prazos definidos.
*   **Notificações Inteligentes**: Avisa você no momento exato, mesmo que o aplicativo esteja em segundo plano.

### Exemplos de uso:
- "Me lembre de ligar para o médico amanhã às 15h."
- "Agende um lembrete para tirar o bolo do forno em 20 minutos."
- "Quais são meus lembretes para hoje?"

### Nota:
Este é um componente essencial para manter sua rotina organizada com a ajuda da MomAI.
