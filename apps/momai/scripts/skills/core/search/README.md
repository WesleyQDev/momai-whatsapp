# Pesquisa na Internet (Componente de Sistema)

Esta funcionalidade permite que a MomAI consulte a internet para responder suas dúvidas com informações sempre atualizadas. É ideal para saber as últimas notícias, conferir fatos ou pesquisar qualquer assunto novo.

### O que ela faz por você:

- **Busca Informações Atuais**: Encontra respostas para coisas que acabaram de acontecer.
- **Fontes Diversas**: Analisa vários sites para te dar uma resposta completa.
- **Citações**: Ela te mostra de onde veio a informação para que você possa confiar no que está lendo.

### Exemplos do que você pode perguntar:

- "Quais são as notícias de hoje sobre tecnologia?"
- "Quem ganhou o jogo de futebol ontem à noite?"
- "Qual o preço atual do dólar?"
- "Me conte as últimas novidades sobre inteligência artificial."

### Nota:

Este é um componente nativo da MomAI e já vem configurado para garantir que sua assistente tenha sempre a resposta certa.
