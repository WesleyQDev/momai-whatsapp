# Clima e Previsão (Componente de Sistema)

Este recurso permite que a MomAI informe como está o tempo em qualquer lugar do mundo. É perfeito para você saber se precisa levar um casaco ou se o dia será bom para um passeio ao ar livre.

### O que ele mostra para você:
*   **Temperatura**: A temperatura exata e como ela realmente parece (sensação térmica).
*   **Condições do Céu**: Se o dia está ensolarado, nublado, chovendo ou com neve.
*   **Previsão do Dia**: O que esperar para as próximas horas ou para os próximos dias da semana.

### Exemplos do que você pode perguntar:
- "Como está o tempo agora em São Paulo?"
- "Vai chover em Lisboa amanhã?"
- "Qual a previsão para o final de semana no Rio de Janeiro?"
- "Preciso levar um guarda-chuva hoje?"

### Nota:
Este é um componente nativo da MomAI, desenhado para funcionar de forma rápida e exibir cartões visuais fáceis de ler diretamente no seu chat.
