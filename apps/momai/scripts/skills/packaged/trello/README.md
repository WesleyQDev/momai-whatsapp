# Trello Skill

Skill para integracao com a API do Trello no MomAI.

## Ferramentas

- `list_boards` - Lista quadros
- `list_lists` - Lista listas de um quadro
- `list_cards` - Lista cartoes de uma lista
- `get_card` - Detalhes de um cartao
- `create_card` - Cria cartao
- `update_card` - Atualiza cartao
- `move_card` - Move cartao entre listas
- `add_comment` - Adiciona comentario

## Configuracao

Variaveis de ambiente necessarias:
- `TRELLO_API_KEY`
- `TRELLO_TOKEN`
