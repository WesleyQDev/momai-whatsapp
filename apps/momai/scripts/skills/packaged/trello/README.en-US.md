# Trello Skill

Skill for Trello API integration in MomAI.

## Tools

- `list_boards` - List boards
- `list_lists` - List lists in a board
- `list_cards` - List cards in a list
- `get_card` - Card details
- `create_card` - Create card
- `update_card` - Update card
- `move_card` - Move card between lists
- `add_comment` - Add comment to card

## Configuration

Required environment variables:
- `TRELLO_API_KEY`
- `TRELLO_TOKEN`
